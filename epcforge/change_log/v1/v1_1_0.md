## EPCForge v1.1.0 Release Notes

### Added
- BOQ-to-cost-head budget tracking with full Earned Value Management (CPI, SPI, EAC, budget health, schedule status) in Project Budget, driven by submitted Purchase Order/Invoice amounts and approved Timesheet hours per Budget Cost Head.
- Automatic BOQ creation from a Project Template's BOQ Item table when a Project is created from that template, including WBS (Task) linking.
- Milestone-based Payment Schedule on BOQ, auto-populated from Task records flagged as billing milestones (`custom_is_billing_milestone`), with advance/retention deduction and one-click Sales Invoice creation per milestone.
- Custom BOQ buttons: Create Material Request (Material-type rows only), Create Sales Invoice (from a selected payment milestone), Sync Project Milestones.
- In-form BOQ Dashboard tab (Procurement Status, Cost & Margin Analysis, Milestone Payments) with Chart.js visualizations, sharing the same aggregation functions as the Project Dashboard page so the two views never drift apart.
- New single-project Dashboard page: contract value, budget health, procurement coverage, cost by item type and cost head, payment milestones, phase progress.
- BOQ Connections tab now surfaces Material Request, Purchase Order, Purchase Receipt, Purchase Invoice, Sales Invoice, and Quality Inspection, via a new header-level `custom_boq` link field on each, auto-populated on document creation.
- Sidebar "Active Project" switcher: a card and dialog to pick the active project, which scopes list views (BOQ, Tender, Purchase Order, Task, Sales Invoice, etc.) to that project while browsing EPCForge's own workspace sidebar.
- EPCForge Settings is now fully wired: default contract type, retention %, bid bond % (applied to Tender's estimated value), default tender type/procurement method, default EPC role/discipline, per-doctype naming-series overrides, default currency (used by the dashboards), default company (fallback on BOQ-generated documents), and optional email notifications (Tender published to invited bidders; Document Register transmittal to the recipient).
- Budget vs Actual and BOQ Summary reports.

### Fixed
- Tender Summary report crashed with `AttributeError: type object 'MariaDB' has no attribute 'fn'` - `frappe.qb.fn.Count` is not a valid API. Replaced with `Count`/`Order` imported from `frappe.query_builder`.
- BOQ Group and Budget Cost Head are configured as tree doctypes (`is_tree: 1`) but their controllers only inherited `Document`, not `NestedSet` - every node had `lft=0, rgt=0` and the tree view never actually worked. Both now inherit `NestedSet` and the trees have been rebuilt.
- Sales Invoice created from a BOQ payment milestone billed the milestone's `net_payable` (already net of advance/retention), then had retention deducted a second time on submit. Now bills the gross milestone amount so retention is deducted exactly once.

### Security
- The "Supplier" portal role had unrestricted `delete`/`export`/`report`/`share` permissions on Tender and Document Register, letting an external vendor with portal access bulk-export or delete records site-wide. Trimmed to read/write/create/print.
