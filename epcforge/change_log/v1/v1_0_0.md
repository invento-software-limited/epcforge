## EPCForge v1.0.0 Release Notes

### Added
- Comprehensive BOQ (Bill of Quantities) engine with tree structure, margin calculation, and milestone payment schedules.
- Project Budget & Cost Control module with target vs actual variance tracking.
- Tender & Bid Management system with bidder invitations and evaluation reporting.
- Engineering Document Register for version-controlled drawings, RFIs, and submittals.
- Frappe Marketplace release standards and self-contained GitHub Pages documentation site under `docs/`.

### Changed
- Standardized metadata in `hooks.py`, `pyproject.toml`, and `.pre-commit-config.yaml`.
- Integrated automated CI/CD workflows for testing, pre-commit linting, semgrep security audits, and release tagging.

### Fixed
- Module initialization side-effects and package metadata alignment.

### Removed
- Legacy redundant asset configurations.
