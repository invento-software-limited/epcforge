## EPCForge v1.2.0 Release Notes

### Added
- Redesigned BOQ Dashboard tab: contract value by item type, estimated cost with planned margin, actual cost against the estimate (with project completion marked) and billed to client; a procurement strip (BOQ value → requested → ordered → received) for stock material lines; cost and margin by item type; a billing timeline with milestone status; procurement progress per line; and the payment milestones table, flagging milestones past target and milestones marked Invoiced without a linked Sales Invoice. Replaces the Chart.js version, so nothing is loaded from a CDN.
- Redesigned Project Budget Dashboard tab with live figures (recalculated with the budget's own calculation, nothing saved): approved budget by cost head, committed, actual, remaining, an earned-value strip (planned value → earned value → actual cost → EAC), budget vs used by cost head, a performance panel (CPI, SPI, schedule status, health, cost variance, labelled when EVM is entered manually), and budget lines whose committed and actual figures open the Purchase Orders and Purchase Invoices behind them.
- KPI and chart header above the table on BOQ Summary, Budget vs Actual and Tender Summary; clicking a status, cost head, project or tender type sets the report's filters.
- Tender Summary: new Tender Type filter.

### Fixed
- The BOQ dashboard showed amounts as "USD" with lakh notation; it now uses the project company's currency (BDT here), falling back to EPCForge Settings only without a project.
- BOQ procurement coverage added quantities together across different UOMs; coverage is now measured in value, line by line, and ordered/received use company-currency amounts.
- Tender Summary's "From/To Publish Date" filters filtered the submission deadline; they now filter the publish date.
- A record's own dashboard no longer hides its linked Purchase Orders and Receipts when the sidebar's Active Project is a different project; reports keep using their own Project filter.

### Security
- The BOQ dashboard endpoint did not check that the user could read the BOQ; the new BOQ and Project Budget endpoints check it.
- BOQ Summary, Budget vs Actual and Tender Summary used bare query-builder queries that ignored User Permissions (a user restricted to one project saw every project); they now use permission-aware lists.
