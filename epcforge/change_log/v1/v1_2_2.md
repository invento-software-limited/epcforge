## EPCForge v1.2.2 Release Notes

### Added
- Project Dashboard task completion metrics: displays total and completed tasks linked to the project directly in the header metrics.
- Procurement paid tracking: calculates paid quantity, value, and coverage percentage by item and in aggregate across submitted Purchase Invoices (and advance-paid Purchase Orders).
- Phase progress goods-received fallback: for material items and procurement phase entries where percent complete is zero, progress is derived from actual Goods Received (Purchase Receipt) quantities.
- Interactive EVM formula tooltips: hoverable tooltips explaining calculation formulas, thresholds (≥ 1.0 vs < 1.0), and interpretations for Cost Performance Index (CPI) and Schedule Performance Index (SPI).
- Project Dashboard chart interactions: enhanced chart hover interactions and responsive stage strip rendering with currency formatting.

### Fixed
- Project Dashboard phase progress calculation now gracefully falls back to item count progress when phase total amount is zero.
