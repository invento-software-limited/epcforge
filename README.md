### 📦 EPCForge

**EPCForge** is a Frappe app that provides comprehensive Engineering, Procurement, and Construction (EPC) management for Frappe/ERPNext including BOQ, Budgeting, Tendering, and Document Control. 🚀

### ✨ Key Features

- **🎯 BOQ Engine**: Tree-structured Bill of Quantities with rate calculation, revision tracking, and payment schedules.
- **💾 Project Budget**: Budget lines linked to BOQ items with Target vs Actual tracking and variance analysis.
- **🔌 Tender & Bid Management**: Full tender lifecycle management, bidder invitations, and bid evaluation summary.
- **⚡ Document Register**: Engineering document control with versioning, revision tracking, and status workflow.

### 🛠 Usage

1. **Create a Project**: Set up your project in ERPNext standard Project master.
2. **Access EPCForge Tools**: Use the EPCForge dropdown on the Project form to create BOQ, Budget, Tender, or Documents.
3. **Track & Report**: Use the Tender Summary, BOQ Summary, and Budget vs Actual reports for pipeline and financial oversight.
